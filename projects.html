Weather Dashboard

A clean, responsive weather dashboard that displays current weather conditions including temperature, humidity, wind speed, and a 5-day forecast. Designed with a minimal card-based layout and a focus on readability and visual clarity.

The project was built as a front-end layout exercise — structuring complex data visually using only HTML and CSS. Every component (forecast cards, temperature gauges, location header) was hand-coded without any CSS frameworks.

WHAT I LEARNED
  • Structuring multi-section layouts using CSS Flexbox and Grid
  • Creating responsive designs with media queries for mobile and desktop
  • Using CSS custom properties (variables) for consistent theming
  • Designing reusable card components with hover effects and transitions

HTML · CSS · JavaScript

To-Do List App

A fully functional task management application built with vanilla HTML, CSS, and JavaScript. Users can add new tasks, mark them as complete, delete them, and assign priority labels (High / Medium / Low) to organise their workload.

The app uses the browser's localStorage API to persist tasks between page refreshes — so your list is never lost when you close the tab. This was my first project introducing JavaScript DOM manipulation and event handling.

KEY FEATURES
  • Add, delete, and mark tasks as complete with instant DOM updates
  • Priority tags (High / Medium / Low) with colour-coded badges
  • Data persistence via localStorage — tasks survive page reloads
  • Filter view: show All / Active / Completed tasks
  • Task counter showing remaining incomplete items
  • Fully responsive — works on mobile and desktop
